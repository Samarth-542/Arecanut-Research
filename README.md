# Arecanut Research Starter

This archive contains the initial project specification and proposed modular folder structure.

## Start here
1. Read `prd.md` for project goals and requirements.
2. Read `rules.md` before changing data or running experiments.
3. Read `memory.md` for persistent context and current status.
4. Read `architecture.md` for the proposed pipeline.
5. Create the folders shown in `STRUCTURE.txt`.
6. Download and extract the Zenodo dataset locally; do not commit it to Git.

Dataset: https://zenodo.org/records/19426901

The architecture is a starting proposal. Verify dataset details, annotations, and the paper methodology before implementing segmentation or fusion.
